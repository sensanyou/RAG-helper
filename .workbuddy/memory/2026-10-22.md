## 修掉 SLF4J multiple bindings 警告

- 警告：`Class path contains multiple SLF4J bindings`（logback-classic 1.2.12 + log4j-slf4j-impl 2.17.2）。
- 溯源：**不是 chroma**，是 `langchain4j-milvus` → `milvus-sdk-java:2.3.9` → `log4j-slf4j-impl`（在 milvus-sdk 的 pom 里，非 test scope）。
- 修法：`pom.xml` 中给 `langchain4j-milvus` 加 `<exclusion>` 排掉 `org.apache.logging.log4j:log4j-slf4j-impl`，注释说明只排 impl、不排 log4j-api。
- 验证：警示消失，`Started ... in 9.609 seconds`，`/api/documents` HTTP 200，文档列表 16ms→5.4ms，缓存三区正常。
- 注：`mvn dependency:tree` 在本机**离线模式跑不了**（plugin 自身依赖没下载），排查依赖来源改用 grep `.m2` 里的 `*.pom` 反查。
