## start.bat 启动失败：PATH 里没有 java（11:40）

- 用户反馈"双击 start.bat 没出现 Started"。
- 排查：Redis 正常（6379 监听）、MySQL 正常（3306 + 连通性 OK）、jar 存在，但无 java 进程。
- 根因：**本机 PATH 里没有 java**（沙箱环境同样没有）。cmd 直接跑 `java -jar` 报"不是内部或外部命令"，用户看到的是窗口里一行报错 + "应用已退出"。
- 验证：前台全路径跑 jar，`Started in 7.905 seconds`，应用本身完全正常。
- 修复：`start.bat` 增加 JDK 定位逻辑——优先 `C:/Program Files\Java\jdk-17.0.19\bin\java.exe`，不存在再退回 PATH java，两者都没有则明确报错。
- 已后台启动应用（PID 5388，8083 监听），用户可直接用。
- 教训：**诊断"启动没出现"类问题，先查进程/端口，别只看配置**。用户的 PATH 与沙箱 PATH 都缺 java，IDEA 内部能跑是因为它用自己配置的 JDK。
